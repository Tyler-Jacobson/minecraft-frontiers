# Documentation Context
- This project includes a folder named `/docs` containing hundreds of documentation files.
- When I ask about attached docs, or ask you to implement a new feature, prioritize the information found in these JSON files.

- The files in `/docs/1.20-Support-Exports` are support tickets raised by devs working with KubeJS.
- The files in `/docs/EntityJS.wiki` are official documentation on EntityJS. Prioritize the information found in these files when answering questions about Entities and EntityJS.
- The files in `/docs/Example-Script-Exports` are example scripts written by devs working with KubeJS. These files can be considered as community generated documentation
